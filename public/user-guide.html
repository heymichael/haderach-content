Arcade Management Platform — User Guide

Signing In

Arcade Management Platform uses Google sign-in. Your session is shared across all applications in the platform, so you only need to sign in once.

1

Open the platform

Navigate to the platform URL. You'll see the home screen with a sign-in prompt.

2

Sign in with Google

Click "Sign in" and authenticate with your Google account.

3

You're in

Once signed in, you'll be redirected to your default application.

Your session persists across apps. Signing in to one application (Vendors, Commodities, or Settings) signs you into all of them. You won't be asked to re-authenticate when switching between apps.

Navigation

The platform is organized around domains. Each domain is a self-contained workspace with its own AI agent, dashboards, and data views.

The left rail

The left rail lists your available domains. Selecting a domain loads its workspace—agent, views, and tools specific to that domain. The domains you see depend on your assigned roles:

Application What it is URL
Vendors Vendor directory, spend analytics, and AI agent for vendor management /vendors/
Commodities Commodity tracking, pricing, and market analysis /stocks/

The account menu

Your avatar in the bottom-left corner of the rail opens the account menu with access to Settings and Log out. Settings takes you to the admin hub where you can access system and vendor administration (if your role allows it).

Layout & Display Modes

Inside each domain, the interface is built around an app rail, a toolbar, and a main content area. The toolbar controls which views are visible.

The app rail

The left rail lists the available domains. Clicking a domain loads its workspace—the agent, views, and tools specific to that domain.

The toolbar

The top toolbar lets you choose which panes are visible. You can show the agent, a view, or both side-by-side. There are four display modes:

1

Full-screen agent

Select Chat, deselect everything else. The agent fills the entire content area.

2

Full-screen view

Select a view, deselect Chat. The dashboard or database fills the screen.

3

Agent + view

Select Chat plus a view. Agent on the right, view on the left, side-by-side.

4

Switch the view

Select a different view while Chat stays open. The view swaps, the conversation persists.

Recommended workflow: Start with the agent in full-screen to ask questions and explore your data. When you need a visual overview, switch to agent + dashboard side-by-side. Use the database view when you need to browse, search, or edit records directly.

Providing Feedback

Your feedback directly shapes how the platform improves. There are two ways to provide it.

Agent feedback

Every agent response has thumbs up and thumbs down buttons. This feedback is reviewed daily and is the most impactful way to improve the agent's accuracy. When something is wrong—a bad answer, a confusing response, a missed intent—a thumbs-down (with an optional comment) goes straight into the review queue. Even a thumbs-up without a comment is valuable because it reinforces good behavior.

Agent feedback is reviewed daily. Every flagged response is triaged, and patterns in feedback drive prompt tuning, tool improvements, and bug fixes. This is the single most important thing you can do to make the agent better.

General feedback

For feedback about the platform itself—UI issues, feature requests, workflow suggestions—reach out to your admin. This covers anything outside of individual agent responses: navigation, dashboard layout, data display, and general usability.

Using the Agent

The AI agent is the primary interface for interacting with your data. Every domain has its own agent that understands that domain's data and tools.

Starting a Conversation

The agent works like a chat interface. Type a question or instruction in the message box and hit Enter. The agent understands natural language—you don't need special commands or syntax.

When a query returns more than 10 results, the agent will summarize the data in chat and offer a downloadable CSV with the full list. A download button appears inline so you can export the complete results to a spreadsheet.

Uploading an edited CSV

1

Download the CSV

Click the download button the agent provides.

2

Open in Excel, Google Sheets, or any CSV editor. Change the fields you need.

3

Upload back

Vendor Management

A complete vendor management workspace with spend analytics, a vendor database, and an AI agent—all in one place.

The Vendor Database

A searchable, sortable table of all your vendors. Browse vendors, view full details, and make inline edits without leaving the page.

Browsing and searching

The database view shows a table of vendor records with key fields visible at a glance. Use the search bar at the top to filter vendors by name. Column headers are sortable—click to sort ascending, click again for descending.

Vendor detail panel

Click any row to open the detail flyout on the right. The panel shows all fields for that vendor—profile information, metadata, owner, department, payment details, and related data—in one place. You can edit fields directly in the detail panel.

Editing in the database view

The database view supports direct editing. Click on a field in the detail panel to modify it. Changes are saved when you confirm. This is the same data the agent operates on, so changes made here are immediately reflected in agent conversations and vice versa.

Agent and database are in sync. If you edit a vendor through the agent, the database view updates. If you edit in the database view, the agent sees the new data. There's one source of truth.

The Spend Dashboard

Visual spend analytics with charts and summary metrics. Use the dashboard for at-a-glance insights and the agent for deeper analysis.

Dashboard views

The spend dashboard provides charts and summary metrics for your vendor spend. Filters let you narrow by department, payment method, time period, and other dimensions. The dashboard operates independently of the agent—it's a traditional, visual interface for quick overviews.

When to use the dashboard vs. the agent

Use the dashboard when… Use the agent when…
You want a visual overview of spend trends You need a specific number or answer to a question
You're scanning for anomalies or outliers You want to drill into a specific vendor or service
You need to present a chart to someone You want to compare spend across custom dimensions
You're doing exploratory analysis You want to export filtered data as CSV
Try them side-by-side. Set the toolbar to show the dashboard plus the agent. Explore visually with the dashboard on the left while asking the agent for specifics on the right.

Access & Permissions

How the platform determines what data you can see and what actions you can take.

How Access Works

Every request is authenticated with your identity. Access controls are applied server-side before any results are returned, so the AI agent only ever sees data you are authorized to access.

Vendor data access

All users can view vendor profiles (names, departments, metadata). Spend data visibility is determined by your access configuration:

Access Control What it does Example
Allowed Departments Grants access to spend for all vendors in those departments Allowed: Engineering, Product → see spend for all vendors in those departments
Allowed Vendors Adds individual vendors to your access set, regardless of department You have Engineering access but can also see a specific Marketing vendor
Denied Vendors Removes specific vendors from your access set (overrides the above) You have Engineering access but a sensitive vendor is excluded
The formula: Your effective access = (Vendors in Allowed Departments ∪ Allowed Vendor IDs) − Denied Vendor IDs. This is computed server-side on every request. The AI model only sees pre-filtered, aggregated results.

Hidden vendors

Admins can mark vendors as hidden from agent. These are excluded from all agent search, list, and analytics results for every user, regardless of role. This is useful for internal or test vendors that shouldn't appear in chat.

Roles

Roles determine which applications you can access and what level of data visibility you have.

Troubleshooting & Tips

Solutions to common issues and tips for getting the most out of the platform.

Common Issues

Quick solutions for the most frequently encountered situations.

"Not authorized" responses

If the agent says you're not authorized to view a vendor's spend or edit a vendor, it means that vendor is outside your allowed set. Your access is determined by your department assignments and vendor allow/deny lists. Contact your admin to request access to additional departments or vendors.

"No spend data" for a vendor

This can happen for two reasons: the vendor genuinely has no spend recorded for the requested period, or you don't have access to that vendor's spend data. If you believe you should have access, check with your admin.

The agent seems confused or gives a wrong answer

Try rephrasing your question more specifically. If the agent is still off, use the thumbs-down button and optionally leave a comment. You can also start a new conversation to reset the context if the current thread has become confusing.

CSV upload rejected

The upload validator checks every row before allowing a confirm. Common issues:

  • Missing or invalid ID — Every row must have a valid vendor ID from the original export.
  • Invalid enum value — Fields like department or payment method must match existing values.
  • Unauthorized vendor — You can only edit vendors in your allowed set.

Fix the flagged rows in your spreadsheet and re-upload.

Session expired

If you see a sign-in prompt after being idle, your session has expired. Sign in again—you'll be returned to where you were. Open conversations are not preserved across sessions.

Tips for Power Users

Get more out of the platform with these practical tips.

  • ↔
    Use side-by-side mode — Put the agent next to the dashboard or database view. Ask the agent for specifics while keeping the visual context visible.
  • ↓
    Export early, filter in the spreadsheet — For complex analysis, ask the agent for a CSV export and do the heavy lifting in Excel or Sheets. Bulk updates are faster than one-by-one edits.
  • ↪
    Use follow-ups — The agent remembers conversation context. Start broad ("total spend this year") and drill in ("break that down by department", "now show me Engineering only"). You don't need to repeat filters.
  • ★
    Be specific with time periods — "Last quarter" and "Q1 2026" both work, but specific periods avoid ambiguity.
  • ✎
    Say "edit" to open the form — If you need to update multiple fields on one vendor, saying "edit Datadog" opens the full form instead of doing field-by-field updates through chat.
  • 🔎
    Don't worry about exact names — The agent uses fuzzy matching. "datadog", "Datadog", or even "datdog" will usually find the right vendor.
AI data handling. The agent sends pre-filtered, aggregated results to the AI model (currently OpenAI) to compose natural language responses. How the AI provider handles that data is governed by the settings in your AI platform account. Review and configure those policies to match your organization's requirements.
